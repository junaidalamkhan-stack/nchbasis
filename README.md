# nchbasis.lib — left H-bases in noncommutative G-algebras (Singular)

Companion code for the paper

> M. Abdul Basit Khan and Junaid Alam Khan, **Computing left H-bases in noncommutative G-algebras by Rees homogenization**.
> Department of Mathematical Sciences, Institute of Business Administration (IBA), Karachi, Pakistan.

The paper develops left H-bases for left ideals in G-algebras graded by an integral weight vector ω, which may have negative components (as in the Weyl algebras and U(sl₂)). Termination is obtained by Rees homogenization, and the H-basis property is decided by an effective syzygy criterion (Theorem 4.17) through finitely many left Gröbner-basis membership tests in A[s]. The library `nchbasis.lib` implements this for the computer algebra system [Singular](https://www.singular.uni-kl.de), using its noncommutative subsystem Plural.

## Installation

Requires Singular (tested with 4.3.2). Copy `nchbasis.lib` to your working directory, or to a directory on Singular's library search path (`SINGULARPATH`), and load it together with Singular's `nctools.lib`:

```
LIB "nchbasis.lib";
LIB "nctools.lib";
```

## Quick start (Example 4.22 of the paper)

```
LIB "nchbasis.lib";
LIB "nctools.lib";
ring R = 0, (x, y, dx, dy), dp;
def A2 = Weyl();              // second Weyl algebra: dx*x = x*dx + 1, dy*y = y*dy + 1
setring A2;
intvec w = 1, 1, -1, -1;      // weight vector for (x, y, dx, dy)
list H0 = x*dy + dx, y*dx + dy;
list H = lhbasis(H0, w);
H;                            // x*dy+dx, y*dx+dy, dx^3-dy^3
```

`lhbasis` declares local variables inside a loop, so Singular prints `// ** redefining …` notes while it runs; `option(noredefine);` suppresses them.

## Procedures

| Procedure | Purpose |
|---|---|
| `lhbasis(H0, w)` | left H-basis of the left ideal generated by the list `H0` with respect to the weight vector `w` (Algorithm 2): syzygies of the ω-initial forms, reduction, and the membership test in A[s]; returns `H0` followed by the adjoined elements |
| `inform(f, w)` | ω-initial form in_ω(f) (Definition 2.4) |
| `informSyzygies(H, w)` | module of syzygies of the initial forms in_ω(h), h ∈ H (Definition 4.11) |
| `lhRed(p, F, w)` | reduction of `p` modulo the list `F` (Example 4.6) |
| `checkMembership(r, H, w, B)` | membership test of Step 9: is the ω-homogenization of `r` in the left ideal of B = A[s] generated by the ω-homogenizations of `H`? |
| `createRingB(A)` | the G-algebra B = A[s] with a central variable `s` (Lemma 4.14) |
| `doHomog(f, w)` | ω-homogenization of `f` with respect to `s` (Definition 4.15) |
| `wplus(w)`, `wminus(w)` | positive part of `w`, and the magnitudes of its negative entries |
| `wdeg(f, w)` | weighted degree deg_ω(f) |
| `worder(f, w)` | auxiliary order v_ω(f) (degree with respect to the positive part of `w`) |
| `homwdeg(F, w)` | degree of an element of the homogenized algebra for the weight (ω₊, 1), where ω₊ = `wplus(w)` and the last variable is the homogenizing one |

The basering must be a G-algebra (a Plural ring, e.g. from `Weyl()` in `nctools.lib` or `makeUsl2()` in `ncalg.lib`) with a global ordering, and `w` must be an `intvec` with one entry per ring variable that is admissible for the algebra and grades it (Remark 2.5).

## Examples (`examples/`)

| Session | Paper | Content |
|---|---|---|
| `example_4_6.sing` | Example 4.6 | `wminus`, `wplus`, `worder`, `wdeg` and `lhRed` in A₂ with ω = (1, 1, −1, −1) |
| `example_4_20.sing` | Example 4.20 | Algorithm 2 in A₁ with ω = (1, −1); no adjunction, H = H₀ |
| `example_4_21.sing` | Example 4.21 | Algorithm 2 in U(sl₂) with ω = (1, −1, 0) and H₀ = {e²f + f, ef + fh} |
| `example_4_22.sing` | Example 4.22 | initial forms, their syzygies and the left H-basis in A₂ |

Each session has its output stored next to it (`*_output.txt`).

In Example 4.21 the library returns {e²f + f, ef + fh, −fh² + 2fh − f, 4f}, while the paper lists {e²f + f, ef + fh, fh² − 2fh + f, −fh³ + 6fh² − 9fh}. Both are left H-bases of the same left ideal I = A·f: the generator 4f is a constant multiple of f, which lies in I (paper, Example 4.21, Pass 3). Left H-bases are not unique, and the elements adjoined depend on the order in which the syzygies are processed.

## Tests

```
./run_tests.sh             # run every session and compare with the stored outputs
./run_tests.sh --update    # regenerate the stored outputs
```

`tests/same_ideal.sing` checks for Examples 4.20–4.22 that the basis returned by `lhbasis` begins with the input H₀ and generates the same left ideal, and that the basis of Example 4.21 printed in the paper generates that ideal as well. All outputs were produced with Singular 4.3.2 (build 4330) on Ubuntu 24.04.
